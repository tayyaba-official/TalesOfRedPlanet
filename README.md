# Tales of the Red Planet

A children's scroll story for the NASA Space Apps Challenge 2026, "Abandoned but not Forgotten".

## Team members
- Avinash Ahuja
- Ayesha Shoaib
- Tayyaba

## SI (Super Intelligence) use
- Code and writing help: AI-assisted (Claude, Anthropic).
- Illustrations (assets/scene*.jpg, mars.png, clara.jpg): AI-generated with Gemini and ChatGPT, based on NASA images. Each is shown with a visible "AI-generated" label.
- Voices (audio/line*.mp3): AI-generated with ElevenLabs. The MP3 metadata (comment tag) states this.
- The TV news and the robots' and characters' voices are a dramatization.
